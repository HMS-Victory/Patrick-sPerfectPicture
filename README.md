# Patrick's Perfect Picture

A custom full-stack web application built for a local painting business to showcase completed work, detail services, and capture customer quote requests.

## Overview

Designed, built, and deployed independently in under one month for a real-world small business client. The platform replaces manual portfolio sharing with a responsive, self-managed web presence built for lead generation.

## Key Features

- **Project Gallery:** Filterable showcase of interior and exterior painting projects powered by cloud image storage.
- **Quote Request System:** Interactive estimate form with client-side validation and backend processing.
- **Responsive UI:** Mobile-first layout optimized for customers browsing on phones and desktops.

## Tech Stack & Architecture

- **Frontend (`/frontend`):** React, JavaScript, CSS — handles routing, responsive UI components, and form state.
- **Backend (`/backend`):** Node.js, Express — manages API endpoints and server-side logic.
- **Deployment:** Hosted on Netlify with continuous deployment from GitHub.
